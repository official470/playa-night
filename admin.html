GitHub 연결 (처음 한 번만)

편성표는 게임 저장소의 schedule.json 파일에 저장돼요. 저장하려면 이 저장소에만 쓸 수 있는 GitHub 토큰이 필요해요. 토큰은 이 브라우저에만 저장되고 다른 곳으로 보내지 않아요.

  1. GitHub 토큰 만들기를 열어요 (저장소 주인 계정으로 로그인).
  2. Repository access에서 Only select repositories → playa-night를 골라요.
  3. Permissions → Repository permissions → Contents를 Read and write로 바꿔요.
  4. Generate token을 누르고 나온 토큰을 아래에 붙여 넣어요.
