📊 방문 통계 대시보드

✅ 방문 기록은 이미 Firebase(realhouse-club)에 쌓이고 있어요. 대시보드에서 보려면 아래 5번(웹 앱 설정값 붙여넣기)만 하면 돼요. 1~4번은 이미 끝났어요.

아직 통계 서버(Firebase, 무료 요금제)가 연결되지 않았어요. 아래 순서대로 한 번만 설정하면 게임 방문 기록이 쌓이기 시작해요. 카드 등록 없이 무료(Spark) 요금제로 돼요.

  1. Firebase 콘솔에서 프로젝트 추가 → 이름(예: realhouse-club) → 애널리틱스는 꺼도 돼요.
  2. 왼쪽 빌드 → Realtime Database → 데이터베이스 만들기 (위치는 아무거나, 잠금 모드로 시작).
  3. Realtime Database의 규칙 탭에 아래 규칙을 붙여 넣고 게시해요.
  4. 빌드 → Authentication → 시작하기 → Google 사용 설정. 설정 탭의 승인된 도메인에 realhouse.club을 추가해요.
  5. 프로젝트 설정(톱니바퀴) → 내 앱 → 웹 앱 추가(</>) → 나오는 firebaseConfig 내용을 아래 칸에 붙여 넣고 저장을 눌러요. (GitHub 연결이 되어 있어야 해요)

        📅 날짜별 방문자

          GitHub 연결 (처음 한 번만)

          편성표는 게임 저장소의 schedule.json 파일에 저장돼요. 저장하려면 이 저장소에만 쓸 수 있는 GitHub 토큰이 필요해요. 토큰은 이 브라우저에만 저장되고 다른 곳으로 보내지 않아요.

          가장 쉬운 방법 (클래식 토큰)

          1. 게임 저장소 주인 계정(official470)으로 GitHub에 로그인한 상태에서 클래식 토큰 만들기를 열어요. public_repo가 이미 체크돼 있어요.
          2. Expiration(만료일)을 정하고 맨 아래 Generate token을 눌러요.
          3. ghp_로 시작하는 토큰을 복사해서 아래에 붙여 넣고 ‘연결’을 눌러요.
          이 저장소만 쓸 수 있는 세분화 토큰으로 만들기 (더 안전)
          1. 세분화 토큰 만들기를 열어요.
          2. Repository access에서 Only select repositories를 고르고 playa-night를 선택해요. (기본값인 Public repositories로 두면 쓰기 권한이 안 보여요)
          3. 그러면 아래 Permissions에 Repositories 항목이 생겨요. Add permissions를 눌러 Contents를 체크하고, 옆의 Access를 Read and write로 바꿔요.
          4. Generate token → 나온 github_pat_ 토큰을 붙여 넣어요.
          ⚡ 전체 자동 편성
          모든 부스(21곳)의 지금부터 24시간 빈 시간을 채워요. Mixcloud는 그 부스 장르의 인기 세트, SoundCloud는 리얼하우스 추천과 ‘내 SoundCloud’에 불러온 목록을 써요. 이미 편성한 시간은 그대로 둬요.
