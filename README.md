# 플라야 나이트 (Playa Night) 3D 페스티벌 게임

브라우저에서 바로 실행되는 3D 페스티벌 게임이에요. 파일 하나(`index.html`)에 게임 전체가 들어 있어요.

## 폴더 구성

```
playa-night/
├── index.html                      게임 본체
├── admin.html                      DJ 편성 관리 페이지 (운영자용)
├── schedule.json                   편성표 (관리자 페이지가 저장)
├── deploy.sh                       수정 사항을 GitHub Pages에 올리는 스크립트
├── media/                          스피어 돔 영상 10편 (index.html과 같은 폴더 구조로 올려 주세요)
│   ├── sphere-video2*.mp4, sv03~sv11.mp4      HD (휴대폰용)
│   └── *-4k.mp4                                4K (컴퓨터용, 가벼운 버전에는 없어요)
└── README.md                       이 설명서
```

## 실행 방법

1. **가장 간단한 방법**: `index.html`을 크롬, 사파리, 엣지 같은 브라우저로 열어요.
2. **휴대폰이나 친구와 함께**: GitHub Pages, Netlify, Vercel 같은 무료 호스팅에 `index.html`을 올리면 주소로 접속할 수 있어요.

인터넷 연결이 필요해요. three.js 라이브러리와 글꼴을 CDN에서 불러와요.

## 조작법

- **컴퓨터**: WASD 또는 방향키 이동, Shift 달리기, Space 점프, E 상호작용, F 제자리 춤, 숫자키 춤 선택, 드래그로 시점, 휠로 줌
- **휴대폰**: 왼쪽 화면 조이스틱으로 이동, 오른쪽 드래그로 시점, 두 손가락으로 줌, 화면 버튼으로 상호작용, 💃 춤, 🎲 막춤 룰렛
- 메뉴: 스타일 꾸미기(브랜드샵, 내 옷장, 3D 미리보기), 맵 이동, 캠프 지도, DJ 플레이리스트, 가방, 화질 설정, 조작법

## 저장되는 것

코인, 산 아이템, 가방, 플라야 이름 등은 브라우저 저장소(localStorage)에 남아요. 다른 브라우저나 기기로 옮기면 처음부터 시작해요.

## DJ 편성 관리 (관리자 페이지)

게임 주소 뒤에 `/admin.html`을 붙여 열면 (예: https://official470.github.io/playa-night/admin.html) 부스마다 시간대별로 틀 DJ 세트를 정할 수 있어요. 편성된 시간에는 그 부스 가까이에 있는 모든 사람이 같은 세트의 같은 부분을 들어요. 편성이 없는 시간에는 평소처럼 그 장르의 인기 DJ 세트가 랜덤으로 나와요.

**처음 한 번: GitHub 연결**
1. 관리자 페이지의 ‘GitHub 연결’에서 안내대로 토큰을 만들어요. (Only select repositories → playa-night, Contents → Read and write)
2. 토큰을 붙여 넣고 ‘연결’을 눌러요. 토큰은 그 브라우저에만 저장돼요.

**편성하기**
1. 왼쪽에서 부스를 골라요. (사막점 9개 부스와 재즈·디스코·파티 포티, 이태원 4F 쉘터·5F 페이퍼, 남이섬 스테이지 6곳, 스피어)
2. Mixcloud 또는 SoundCloud 세트 주소를 넣으면 제목, DJ, 이미지, 길이를 자동으로 불러와요.
3. 시작 시각과 길이(분)를 정하고, 원하면 DJ 소개와 음악 소개를 써요. 게임 속 음악 카드에 그대로 나와요.
4. ‘편성표에 추가’ 후 위의 ‘게임에 게시하기’를 누르면 1~2분 뒤 게임에 반영돼요.

편성표는 저장소의 `schedule.json`에 저장돼요. Mixcloud Select 구독자 전용 세트나 퍼가기가 막힌 SoundCloud 트랙은 재생되지 않아요.

## Mixcloud DJ 세트 (로그인, 앱 키 필요 없음)

게임을 GitHub Pages나 Netlify에 올린 주소로 열면, 모든 맵의 스테이지(사막점 부스, 이태원 클럽, 남이섬 스테이지, 스피어, 아트카)에서 Mixcloud의 공식 DJ·레이블 채널 믹스셋을 원본 그대로 틀어요.

- **자동 재생**: 스테이지에 가까이 가면 그 장소에 맞는 장르 세트가 바로 나와요. 다른 스테이지로 가면 그 장르로 바뀌고, 멀어지면 소리가 작아져요.
- **부스마다 그 장르만**: 각 부스(스테이지) 가까이에서만 그 부스 장르의 세트를 틀 수 있어요. 사이키델릭 부스는 The Psytrance Network Show, 하드스타일 부스는 Q-dance 채널 세트가 나와요.
- **음악 카드**: 화면 아래 미니 카드에 지금 나오는 세트의 앨범 이미지, 제목, DJ가 보여요. ▶를 누르면 그 부스 장르의 세트 중 하나가 랜덤으로 나오고, ⏭도 랜덤으로 넘겨요. 카드를 누르면 펼쳐져서 큰 앨범 이미지와 DJ 소개, 음악 소개(한국어 자동 번역)가 나오고, 다른 곳을 누르면 다시 미니로 접혀요.
- **어떤 세트가 나오나요**: 장르마다 공식 DJ·레이블 채널과 Mixcloud에서 가장 많이 재생된 믹스를 모아, 재생 수가 많은 40개 중에서 랜덤으로 틀어요. 라디오 쇼·팟캐스트·인터뷰처럼 말이 들어가는 형식, 논스톱 메들리·리믹스 모음, 장르와 다른 파티 믹스는 빼요. 관리자가 편성한 시간에는 편성된 세트가 우선이에요.
- **스테이지 군중**: 스테이지에서 2분 넘게 춤추면 사람들이 하나둘 스테이지 맨 앞으로 모여들고, 시간이 지날수록 더 많이, 더 빽빽하게 모여요.
- 게임에 내장돼 있던 자체 제작 곡과 내 음악 파일 넣기 기능은 없앴어요. 음악은 모두 Mixcloud DJ 세트예요.
- **휴대폰**: 브라우저가 자동 재생을 막으면 화면 아래에 Mixcloud 플레이어가 나타나요. 재생 버튼을 한 번 누르면 그 뒤로는 세트가 바뀌어도 계속 이어서 나와요.
- Mixcloud Select 구독자 전용 믹스는 플레이어에서 재생되지 않아서 목록에서 빼요.
- Claude 링크 안에서는 작동하지 않아요.

## 가격 설정 메모

- 스피어 입장료: `index.html`에서 `SPH_PRICE=0`을 `500`으로 바꾸면 유료로 돌아가요.
- 버닝맨 입장권은 매표소 팝업 문구와 함께 한시 무료로 설정돼 있어요.
