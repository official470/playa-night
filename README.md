# 플라야 나이트 (Playa Night) 3D 페스티벌 게임

브라우저에서 바로 실행되는 3D 페스티벌 게임이에요. 파일 하나(`index.html`)에 게임 전체가 들어 있어요.

## 폴더 구성

```
playa-night/
├── index.html                      게임 본체
├── admin.html                      편성표 관리 페이지 (운영자용)
├── server/schedule-worker.js       편성 서버 (편성 방송 모드를 쓸 때만, Cloudflare Worker)
├── media/                          스피어 돔 영상 10편 (index.html과 같은 폴더 구조로 올려 주세요)
│   ├── sphere-video2*.mp4, sv03~sv11.mp4      HD (휴대폰용)
│   └── *-4k.mp4                                4K (컴퓨터용, 가벼운 버전에는 없어요)
└── README.md                       이 설명서
```

## 실행 방법

1. **가장 간단한 방법**: `index.html`을 크롬, 사파리, 엣지 같은 브라우저로 열어요.
2. **휴대폰이나 친구와 함께**: GitHub Pages, Netlify, Vercel 같은 무료 호스팅에 `index.html`을 올리면 주소로 접속할 수 있어요.

인터넷 연결이 필요해요. three.js 라이브러리와 글꼴을 CDN에서 불러와요.

## 조작법

- **컴퓨터**: WASD 또는 방향키 이동, Shift 달리기, Space 점프, E 상호작용, F 제자리 춤, 숫자키 춤 선택, 드래그로 시점, 휠로 줌
- **휴대폰**: 왼쪽 화면 조이스틱으로 이동, 오른쪽 드래그로 시점, 두 손가락으로 줌, 화면 버튼으로 상호작용, 💃 춤, 🎲 막춤 룰렛
- 메뉴: 스타일 꾸미기(브랜드샵, 내 옷장, 3D 미리보기), 맵 이동, 캠프 지도, 음악 고르기, 가방, 화질 설정, 조작법

## 저장되는 것

코인, 산 아이템, 가방, 플라야 이름 등은 브라우저 저장소(localStorage)에 남아요. 다른 브라우저나 기기로 옮기면 처음부터 시작해요.

## 편성 방송 모드 (모두가 같은 시간에 같은 음악 듣기)

운영자가 부스마다 시간대와 Mixcloud 믹스를 정해 두면, 그 시간에 게임에 있는 모든 유저가 같은 믹스의 같은 부분을 들어요. 늦게 들어온 사람은 처음부터가 아니라 지금 나오는 부분부터 들어요. 유저끼리 1~3초 정도 차이는 날 수 있어요. Claude 링크 안에서는 작동하지 않고, 직접 올린 주소에서만 돼요.

**1. 편성 서버 만들기 (Cloudflare, 무료)**
1. Cloudflare 대시보드 → Workers & Pages → KV에서 namespace를 하나 만들어요 (이름 아무거나, 예: playa-schedule).
2. Workers & Pages → Create → Worker를 만들고, `server/schedule-worker.js` 내용을 그대로 붙여 넣고 Deploy 해요.
3. 그 Worker의 Settings → Bindings에서 KV namespace를 추가하고, 변수 이름을 정확히 `SCHEDULE`로 해요.
4. Settings → Variables and Secrets에서 `ADMIN_PASSWORD`를 Secret으로 추가해요 (편성표 저장용 비밀번호).
5. (선택) `ALLOWED_ORIGIN`에 게임 주소를 넣으면 그 사이트에서만 쓸 수 있어요. 예: https://my-playa.netlify.app
6. Worker 주소를 복사해요. 예: https://playa-schedule.myname.workers.dev

**2. 게임에 서버 주소 넣기**
`index.html`을 메모장 같은 편집기로 열어 `const SCHEDULE_URL='';`를 찾아, 따옴표 안에 Worker 주소를 넣고 저장해요.
예: `const SCHEDULE_URL='https://playa-schedule.myname.workers.dev';`
주소를 넣으면 자동 검색 재생은 꺼지고 편성표대로만 나와요.

**3. 올리기**
playa-night 폴더 전체를 Netlify Drop에 올려요.

**4. 편성하기**
올린 주소 뒤에 `/admin.html`을 붙여 열어요 (예: https://my-playa.netlify.app/admin.html).
서버 주소와 비밀번호를 넣고 불러오기 → 부스를 고르고 시간대 추가 → 시작 시각(한국 시간), Mixcloud 믹스 주소, 제목, 길이(분, 비우면 다음 시간대까지)를 넣고 편성표 저장을 눌러요. 1분 안에 모든 유저에게 반영돼요.

편성할 수 있는 곳: 사막점 9개 부스, 이태원 4F 쉘터와 5F 페이퍼. 편성이 없는 시간에는 그 부스의 기본 게임 음악이 나와요.

## Mixcloud DJ 세트 (로그인, 앱 키 필요 없음)

게임을 GitHub Pages나 Netlify에 올린 주소로 열면, 모든 맵의 스테이지(사막점 부스, 이태원 클럽, 남이섬 스테이지, 스피어, 아트카)에서 Mixcloud의 공식 DJ·레이블 채널 믹스셋을 원본 그대로 틀어요.

- **자동 재생**: 스테이지에 가까이 가면 그 장소에 맞는 장르 세트가 바로 나와요. 다른 스테이지로 가면 그 장르로 바뀌고, 멀어지면 소리가 작아져요.
- **부스마다 그 장르만**: 각 부스(스테이지) 가까이에서만 그 부스 장르의 세트를 틀 수 있어요. 음악 패널의 **🎛️ DJ 세트 틀기** 또는 하단 스테이지 바의 **🎛️ DJ** 버튼에서 다른 세트로 넘기기, 일시정지, 자동 재생 끄기를 할 수 있어요. 사이키델릭 부스는 The Psytrance Network Show, 하드스타일 부스는 Q-dance 채널 세트가 나와요.
- **휴대폰**: 브라우저가 자동 재생을 막으면 화면 아래에 Mixcloud 플레이어가 나타나요. 재생 버튼을 한 번 누르면 그 뒤로는 세트가 바뀌어도 계속 이어서 나와요.
- Mixcloud Select 구독자 전용 믹스는 플레이어에서 재생되지 않아서 목록에서 빼요.
- Claude 링크 안에서는 작동하지 않아요.

## 가격 설정 메모

- 스피어 입장료: `index.html`에서 `SPH_PRICE=0`을 `500`으로 바꾸면 유료로 돌아가요.
- 버닝맨 입장권은 매표소 팝업 문구와 함께 한시 무료로 설정돼 있어요.
